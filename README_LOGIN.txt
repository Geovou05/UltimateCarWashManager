ULTIMATE CAR WASH MANAGER v14 LOGIN

1. Ανέβασε ΟΛΑ τα αρχεία αυτού του φακέλου στο root του GitHub repository, αντικαθιστώντας τα παλιά.
2. Στην πρώτη εκκίνηση θα σου ζητηθεί να ορίσεις username και εξαψήφιο PIN.
3. Μετά από 5 λάθος προσπάθειες η σύνδεση κλειδώνει για 5 λεπτά.
4. Η επιλογή «Να με θυμάται» ισχύει μόνο στη συγκεκριμένη συσκευή/browser.
5. Η εφαρμογή κλειδώνει μετά από 5 λεπτά αδράνειας.

Σημαντικό: Το login προστατεύει τα τοπικά δεδομένα από απλή πρόσβαση στη συσκευή. Το GitHub Pages παραμένει δημόσιο ως ιστοσελίδα, αλλά άλλες συσκευές δεν βλέπουν τα δικά σου τοπικά δεδομένα.
