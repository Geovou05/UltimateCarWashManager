ULTIMATE CAR WASH MANAGER v2 — iPhone/PWA + Google Calendar

Περιλαμβάνει:
• Πελάτες / πινακίδες / οχήματα
• Υπηρεσίες, συχνές υπηρεσίες και ιστορικό αλλαγών τιμής
• Νέο πλύσιμο, πληρωμή, μερική πληρωμή, οφειλή
• Αναίρεση καταχώρησης και εξόφληση οφειλής
• Ημερήσια / μηνιαία στατιστικά
• Backup / restore
• Εγκατάσταση ως PWA στην αρχική οθόνη iPhone
• Google Calendar: σύνδεση, προβολή επόμενων ραντεβού, δημιουργία ραντεβού

ΓΙΑ GOOGLE CALENDAR:
1) Η εφαρμογή πρέπει να τρέχει σε HTTPS hosting (όχι απλώς ως τοπικό αρχείο).
2) Στο Google Cloud δημιουργείς project, ενεργοποιείς Google Calendar API,
   ρυθμίζεις OAuth consent screen και δημιουργείς OAuth Client ID τύπου Web application.
3) Στα Authorized JavaScript origins βάζεις ακριβώς το HTTPS domain όπου ανέβηκε η εφαρμογή.
4) Βάζεις το Client ID μέσα στην εφαρμογή: Περισσότερα > Ρυθμίσεις Google.
5) Πατάς Ημερολόγιο > Σύνδεση Google Calendar και εγκρίνεις την πρόσβαση.

ΓΙΑ iPHONE:
Άνοιξε το HTTPS URL στο Safari > Κοινή χρήση > Προσθήκη στην οθόνη αφετηρίας.

ΣΗΜΕΙΩΣΗ:
Το πραγματικό logo του Ultimate Car Wash δεν ήταν διαθέσιμο στο αρχείο της συνομιλίας κατά τη δημιουργία,
οπότε υπάρχει προσωρινό εικονίδιο “U”. Αντικατέστησε το icon.svg με το πραγματικό logo όταν είναι διαθέσιμο.

Τα δεδομένα πελατών αποθηκεύονται τοπικά στο browser/PWA. Χρησιμοποίησε τακτικά το Backup.
