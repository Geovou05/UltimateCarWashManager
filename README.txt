ULTIMATE HAND CAR WASH MANAGER v17

Ανέβασε ΟΛΑ τα αρχεία αυτού του φακέλου στον κεντρικό φάκελο του GitHub repository.

Κύριες αλλαγές:
- Πλήρης εμφάνιση βασισμένη στο επίσημο φυλλάδιο.
- Πραγματικό λογότυπο στην είσοδο και στην εφαρμογή.
- Νέο εικονίδιο εφαρμογής.
- Splash screen.
- Εύκολο backup μέσω κοινής χρήσης σε Αρχεία / iCloud Drive.
- Νέα cache ώστε να φορτωθεί η νέα έκδοση.

Τα δεδομένα της εφαρμογής παραμένουν αποθηκευμένα στη συσκευή και δεν διαγράφονται από την αναβάθμιση.
