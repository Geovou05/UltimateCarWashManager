ULTIMATE CAR WASH MANAGER v13

Ανέβασε ΟΛΑ τα παρακάτω αρχεία στον κεντρικό φάκελο του GitHub repository:
- index.html
- manifest.json
- service-worker.js
- icon.svg
- icon-192.png
- icon-512.png

Στο GitHub Pages περίμενε 1-2 λεπτά και άνοιξε τη διεύθυνση της εφαρμογής από Safari.
Για προσθήκη σε iPhone: Κοινή χρήση > Προσθήκη στην οθόνη Αφετηρίας.

Η νέα έκδοση χρησιμοποιεί network-first φόρτωση για το index.html, ώστε οι επόμενες αναβαθμίσεις να εμφανίζονται χωρίς να κολλάει η παλιά έκδοση στην προσωρινή μνήμη.

ΣΗΜΑΝΤΙΚΟ: Τα δεδομένα της εφαρμογής αποθηκεύονται στη συσκευή μέσω localStorage. Κάνε συχνά Εξαγωγή Backup από τις Ρυθμίσεις.
